ShipGen Logistics — Local development commands
==============================================

Prerequisites
-------------
- Node.js 18+

First-time setup
----------------
npm install

Run locally (frontend only)
---------------------------
npm run dev

  Frontend:  http://localhost:5173

  Note: contact.php runs on cPanel (PHP). Vite does not execute PHP locally.

Build for production (creates dist/ folder)
-------------------------------------------
npm run build

Preview production build locally
--------------------------------
npm run build
npm run preview

  Preview site: http://localhost:4173

Deploy
------
Upload everything inside dist/ to cPanel public_html/
Edit contact.php $CONFIG with live SMTP settings.
